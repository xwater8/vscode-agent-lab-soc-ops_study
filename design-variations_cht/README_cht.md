# 設計變體

此目錄包含社交 Bingo 遊戲的三個完整設計變體規範。

## 內容

### 設計規範

1. **[變體 1：極簡禪花園](variation-1-zen-garden_cht.md)**
   - 採用溫暖大地色的平靜、寧靜設計
   - 微妙的動畫和慷慨的空白區域
   - 專業且普遍適用

2. **[變體 2：復古街機霓虹](variation-2-retro-arcade_cht.md)**
   - 充滿活力的 80 年代/90 年代街機美學
   - 亮霓虹色和像素字體
   - 大膽和易記的遊戲體驗

3. **[變體 3：野蠻派終端](variation-3-brutalist-terminal_cht.md)**
   - 原始、單色命令行界面設計
   - 嚴格網格系統和功能極簡
   - 最大可訪問性和性能

### 分析

- **[COMPARISON_cht.md](COMPARISON_cht.md)** - 所有三種變體的全面並排比較，包括：
  - 關鍵特徵
  - 權衡分析
  - 受眾適應建議
  - 技術實施考慮
  - 性能和可訪問性比較

## 目的

這些變體是設計探索的一部分，用於為社交 Bingo 遊戲識別不同的美學方法。每個變體代表一個完整、連貫的設計系統，可以替換當前的"太空星系發光"主題。

## 當前設計

現有實施使用"太空星系發光"主題：
- 極簡主義宇宙美學
- 深空顏色配霓虹重音（青、洋紅、紫）
- 高能量動畫和星場效果
- Orbitron 和 Space Mono 字體
- 玻璃態和多層光暈

## 使用這些規範

每個變體文件包括：
- 完整色調調色板，配有 CSS 變量名
- 排版系統和字體建議
- 佈局原則和間距系統
- 動畫策略和關鍵幀定義
- 所有主要 UI 元素的組件模式
- 互動狀態規範
- 權衡分析
- 實施說明

要實施變體：
1. 查看完整的規範文件
2. 用新的 `@theme` 變量更新 `src/index.css`
3. 修改組件樣式以匹配設計系統
4. 跨設備和可訪問性設置測試

## 快速比較

| 方面 | 禪花園 | 復古街機 | 野蠻派終端 |
|--------|------------|--------------|-------------------|
| 氛圍 | 平靜精緻 | 有趣充滿活力 | 原始誠實 |
| 顏色 | 溫暖中性 | 深色霓虹 | 單色 |
| 複雜度 | 低 | 高 | 非常低 |
| 最適合 | 企業活動 | 遊戲活動 | 科技會議 |

## 建議

有關根據您的具體需求選擇哪個變體的詳細建議，請參見 **[COMPARISON_cht.md](COMPARISON_cht.md)** 文件。

**概括：**
- 選擇**禪花園**以獲得多功能性和廣泛吸引力
- 選擇**復古街機**以獲得易記遊戲體驗
- 選擇**野蠻派終端**以獲得科技精通受眾和最大可訪問性
