# Soc Ops - Social Bingo Game

Social Bingo game for in-person mixers. Find people who match the questions and get 5 in a row!

## 🎨 Live Theme Switcher

Experience **four distinct design themes** with instant switching - no page reload required!

### Available Themes

1. **🌌 Space Galaxy Glow** - Cosmic neon aesthetic (default)
2. **🌿 Zen Garden** - Minimalist Japanese-inspired calm
3. **🎮 Retro Arcade** - Nostalgic 80s/90s arcade with CRT effects
4. **💻 Brutalist Terminal** - Raw monochromatic terminal interface

### Try It Now

```bash
npm install
npm run dev
```

Visit http://localhost:5173 and click the **🎨 theme button** in the top-right corner to switch between themes instantly!

### Features

- ✨ **Instant switching** - Change themes without reload
- 💾 **Persistent** - Your theme choice is saved to localStorage
- 🎯 **Pure CSS** - No performance impact, just CSS variables
- 🎭 **Complete transformation** - Colors, fonts, animations all change
